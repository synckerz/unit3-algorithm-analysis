# Report planning – approximately 300 words

Write the report in your own words, using the four sections below. Aim for about 300 words in total.

## 1. Introduction (about 40–50 words)
- What is a sorting algorithm?
- Why did you compare Bubble Sort and Quick Sort?

## 2. Implementation (about 60–70 words)
- What does Bubble Sort compare?
- What is the pivot in your Quick Sort implementation?
- Mention that both implementations were written in Python.

## 3. Performance analysis (about 110–130 words)
- Explain that you tested 100, 500, 1,000 and 2,000 items.
- Explain that each size was tested five times and the average was calculated.
- Use the actual values in `../03-Performance-Testing/performance_results.md`.
- Explain the observed difference.
- Relate the results to average and worst-case Big-O values.

## 4. Conclusion and real-world use (about 50–60 words)
- Which algorithm was faster in your experiment?
- Why might a simple algorithm still be useful for learning or very small tasks?
- Why is Quick Sort often more suitable for larger collections in average conditions?

Do not claim that one timing experiment proves performance for every computer or input. Include references required by your module guidance.
