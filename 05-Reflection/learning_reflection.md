# Individual Learning Reflection

One of the main challenges I faced during this project was understanding how to translate algorithmic steps into Python code. Implementing Bubble Sort and Quick Sort helped me understand how programming instructions can be combined to solve a specific problem.

I improved my understanding of loops, conditional statements, lists and recursion. Bubble Sort helped me understand how adjacent elements can be compared and exchanged, while Quick Sort introduced me to the divide-and-conquer approach and recursive problem-solving.

An important part of my learning was comparing the performance of both algorithms. The experimental results showed that Quick Sort was significantly faster than Bubble Sort for the larger data sets tested. This helped me understand the practical importance of algorithm complexity and why software engineers should consider efficiency when selecting an algorithm.

I also learned that performance testing requires a fair methodology. Using the same input data, repeating each test five times and calculating average execution times made the comparison more meaningful.

If I repeated this project, I would explore additional sorting algorithms, test larger data sets and investigate how different pivot-selection strategies affect Quick Sort performance.

Overall, this project improved my confidence in Python programming and strengthened my understanding of algorithm analysis. It also helped me recognise that software engineering involves not only writing code but also evaluating solutions, interpreting results and making informed technical decisions.
