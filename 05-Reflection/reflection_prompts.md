# Learning reflection – write in your own words

The e-Portfolio guide asks you to show self-assessment: strengths, weaknesses, achievements and supporting evidence.

Use these prompts for an honest reflection:
1. What did you find difficult when you started?
2. Which Python ideas did you learn or practise? (For example: lists, indexes, `for`, `if`, `len()`, variables and swapping values.)
3. What error did you encounter, and how did you fix it?
4. What did the performance results teach you?
5. What would you like to improve next?

Use specific examples from your own work. Do not claim skills or understanding you have not yet developed.
